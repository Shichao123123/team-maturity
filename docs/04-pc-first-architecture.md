# PC 端为核心的架构说明

> 更新日期：2026-08-09

## 定位

| 端 | 职责 | 比重 | 现状 |
|----|------|------|------|
| **PC 管理端** | 组织/班组、指标题库、批次、算分判级、赋能措施、看板、导出、权限；成员事后查看/补全 | **核心** | 档案/题库/赋能/系统管理/模拟做题已可用；批次与看板待做 |
| **小程序** | 扫码 → 选单位 → 填姓名 → 做题 → 提交同步 → 看结果 | **辅助答题入口** | **未建**（勿再按手机号预绑档案实现） |

规格书里的「登录 → 测评 → 出结果」在实现上拆成：

1. **PC**：配置组织/班组与标准、发起批次、生成二维码、查看与分析（**不必预导人员**）  
2. **小程序**：扫码后选单位、填姓名完成问卷，提交后同步人员与答卷  
3. **过渡：** PC「模拟做题」用于联调个人算分与判级（不落批次库）

## PC 登录与权限

- 表：`tm_admin` / `tm_role` / `tm_power` / `tm_role_power`
- Session：`tm_user`（文件 Session）
- 默认账号：`admin` / `123456`（仅本地开发）
- 密码：`password_hash`（PHP `PASSWORD_BCRYPT`）

## 开发优先级与完成度

| 序 | 事项 | 状态 |
|----|------|------|
| 1 | PC 登录 + 菜单权限 | ✅ |
| 2 | 组织 / 班组 / 成员页（含导入；成员非开测前置） | ✅ |
| 3 | 指标版本 / 题库 / 等级赋能 | ✅ |
| 3b | 系统管理（管理员/角色/导入任务/日志） | ✅ |
| 3c | 工作台壳 + 模拟做题 | ✅ |
| 4 | 测评批次（绑班组、进度、算分落库、二维码） | ❌ **当前最优先** |
| 5 | 结果查询 + 看板导出 | ❌（工作台分布壳已有） |
| 6 | 小程序：扫码选单位填姓名 + 提交同步 | ❌ |

## 核心服务（已落地）

| 服务 | 路径 | 用途 |
|------|------|------|
| `QuestionPickService` | `service/QuestionPickService.php` | 每三级抽 1 题；模拟做题已调用；批次 start 将复用 |
| `ScoreService` | `service/ScoreService.php` | 个人 Σ(weight×ratio)；薄弱指标+措施；模拟做题已用 |
| `LevelJudgeService` | `service/LevelJudgeService.php` | 按 `tm_level_threshold` 判级 |
| `ImportService` / `ExcelHelper` | `service/` | 组织/班组/成员 Excel |
| `OpLogService` | `service/OpLogService.php` | 写 `tm_op_log` |

## 小程序边界（克制）

只做：扫码进批次、选单位、填姓名、答题、提交同步、结果查看。  
不做：组织维护、题库配置、看板、批次管理；**不做强制手机号预绑档案**。  

接口契约：`docs/03-mini-api.md`（尚未编码；需按新口径实现）。

## 题库题池（预留）

- 三级指标 : 题目 = **1 : N**（当前数据多为 1:1）
- 开测时每个三级 **抽 1 题** 进批次快照（`QuestionPickService`）
- 详设：`docs/05-question-pool.md`  

## 组织树（可变层级）

- 不强制 2/3 层；班组可挂任意组织节点  
- 详设：`docs/06-org-tree.md`

# 组织架构：可变层级

> 更新日期：2026-08-08  
> **实现状态：** PC 组织/班组 CRUD 与导入已按此约定落地（不强制 2/3 层）。

## 约定

- 组织用 `parent_id` 树存储，**不强制 2 层或 3 层**（也可更深）。
- `org_type` 只是展示标签（公司/分厂/部门等），**不代表必须对应第几层**。
- 班组 `tm_team.org_id` 可挂在**任意组织节点**上（常见挂在叶子；两层时也可挂在第二层）。

## 示例

**三层：** 集团 → 分厂 → 工段 → 班组  

**两层：** 公司 → 部门 → 班组  

## 导入

组织 Excel 用「组织编码 / 上级组织编码」表达父子，层数由数据决定，模板不必凑满三层。

## 后续注意

看板按组织下钻、批次按组织筛选时：用树子孙查询，不要写死 `org_type=3`。

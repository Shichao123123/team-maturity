## 二、服务器部署步骤（按顺序勾）

### A. 站点与代码

- [ ] 代码放到服务器目录（如 `/var/www/team-maturity`）
- [ ] Web 根目录 = **`backend/public`**（不要指到仓库根目录）
- [ ] 配置伪静态（ThinkPHP）：请求落到 `index.php`
  - Nginx 示例要点：`try_files $uri $uri/ /index.php?$query_string;`
- [ ] HTTPS 证书绑定该域名，HTTP 可 301 到 HTTPS
- [ ] 目录可写：`backend/runtime/`（日志、缓存、小程序码缓存）
  - Linux 常见：`chown -R www-data:www-data backend/runtime && chmod -R 775 backend/runtime`
- [ ] 在 `backend/` 执行：`composer install --no-dev`（确保含 `tecnickcom/tcpdf`、`firebase/php-jwt` 等）

### B. 数据库

- [ ] 创建库 `team_maturity`，字符集 `utf8mb4`
- [ ] 按序导入 `sql/` 脚本（或导入本机全库备份）
- [ ] 用独立业务账号（非 root）+ 强密码；仅本机/内网可连
- [ ] 用环境变量配置库连接（推荐）：

```bash
export TM_DB_HOST=127.0.0.1
export TM_DB_DATABASE=team_maturity
export TM_DB_USERNAME=tm_user
export TM_DB_PASSWORD='强密码'
```

（也可用 Web 面板 / systemd EnvironmentFile 注入，勿写进公开仓库。）

### C. 应用配置（生产必改）

在服务器创建 `backend/application/config.local.php`（**勿提交 Git**），或用环境变量覆盖：

| 配置项 | 生产值 | 环境变量（可选） |
|--------|--------|------------------|
| `wx_appid` | 真实 AppID | `TM_WX_APPID` |
| `wx_secret` | 真实 Secret | `TM_WX_SECRET` |
| `dev_login` | **`false`** | `TM_WX_DEV_LOGIN=false` |
| `wxacode_env` | 体验先用 **`trial`**；正式发码用 **`release`** | — |
| 调试 | **`TM_APP_DEBUG=false`** | 同上 |
| JWT | 设置随机长密钥 | `TM_JWT_SECRET` |
| Cookie | HTTPS 下自动 secure；也可强制 | `TM_COOKIE_SECURE=true` |

示例 `config.local.php`：

```php
<?php
return [
    'wx_appid'    => 'wxc23577d86aaf957c',
    'wx_secret'   => '生产Secret',
    'dev_login'   => false,
    'wxacode_env' => 'trial', // 正式员工发码前改为 release
];
```

- [ ] 确认生产 **`dev_login=false`**（否则等于允许伪造登录）
- [ ] 确认 **`TM_APP_DEBUG=false`**
- [ ] 确认 **`TM_JWT_SECRET`** 已换成随机串（勿用默认 `tm_mini_dev_secret_change_me`）
- [ ] 浏览器打开 `https://你的域名/` 能进 PC 登录页
- [ ] 用管理员登录后**立刻改密码**

### D. 微信公众平台

登录 [mp.weixin.qq.com](https://mp.weixin.qq.com/) → 你的小程序：

- [ ] **开发 → 开发管理 → 开发设置 → 服务器域名**
  - **request 合法域名**：`https://你的域名`（只填域名，无路径、无端口、必须 https）
- [ ] 保存后等待生效（通常数分钟）
- [ ] （可选）把服务器出口 IP 加入微信 IP 白名单（若平台有相关限制）

### E. 小程序发版

- [ ] 改 `miniprogram/config.js`：

```js
baseUrl: 'https://你的域名'  // 末尾不要 /
```

- [ ] 微信开发者工具上传代码
- [ ] **体验版**：设体验成员 → 内部试扫
- [ ] **正式版**：提交审核 → 发布（给全体员工前必须完成）
- [ ] 服务器 `wxacode_env` 与已发布环境一致（`trial` / `release`）
- [ ] PC 后台对目标批次：**刷新小程序码 → 导出**（文件名=批次名.png），再打印/转发

### PC 管理端

- [ ] 组织/班组可维护
- [ ] 有「已发布」指标版本与题库
- [ ] 新建批次 → 树形绑班组 → **开测** → 详情可见正式小程序码 → 可导出
- [ ] 看板 / 结果查询能打开（有数据后再验算分）

### 小程序（员工侧）

- [ ] 体验成员或正式用户**扫导出的码**能进入（非开发者工具）
- [ ] 选班组 → 填姓名 → 答题 → 提交 → 看到**个人得分**
- [ ] PC 后台该批次进度/结果出现对应答卷

### 失败速查

| 现象 | 优先检查 |
|------|----------|
| `fail url in domain` | 合法域名未配 / 仍是 HTTP / IP / 端口 |
| 扫码进不了或提示版本不对 | `wxacode_env` 与已发版不一致；需重新导出码 |
| 登录失败 | `dev_login` 仍为 true/false 配错；AppSecret 错；域名未生效 |
| 生成小程序码失败 | 服务器出网被拦；Secret 错；runtime 目录不可写 |
| 页面 500 / 空白 | PHP 扩展缺；`runtime` 权限；`composer` 未装；开 `TM_APP_DEBUG` 临时看报错后立刻关掉 |
| 尚未开测 | PC 对该批次点「开测」 |

## 六、可交给运维的一句话需求

> 需要一台可公网访问的服务器：域名 + 有效 HTTPS；Nginx/Apache 站点根目录指向项目 `backend/public`；PHP ≥ 7.3（含 pdo_mysql/curl/openssl/gd/mbstring）；MySQL 5.7+ utf8mb4；目录 `backend/runtime` 可写；服务器能访问微信 API；数据库与微信 Secret 用环境变量或本机私密配置注入，不对公网暴露 3306。

业务侧另需：小程序 AppID/Secret、公众平台「request 合法域名」、小程序体验版/正式版发布权限。

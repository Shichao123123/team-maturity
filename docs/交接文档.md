## 五、关键业务约定（接手必读）

1. **PC 核心**：组织/班组、题库、批次、算分、赋能、看板、权限；成员档案以**事后同步/补全**为主。  
2. **小程序边界（现行）**：**扫码 → 选择单位（组织/班组）→ 填写姓名 → 做题 → 提交后同步人员与答卷入库 → 看结果**；不做配置。  
3. **不必事先导入人员**：开测前置只需组织/班组 + 题库标准 + 批次；人员在作答时现场产生。  
4. **算分**：`weight × score_ratio`；个人求和；班组 = 已提交平均分。  
5. **开测写快照**：`QuestionPickService::buildExamSet` → `tm_batch_indicator_snap`；答题只读快照。  
6. **题池**：三级指标 1:N 题；策略 `first|random|sequential`（版本默认 `random`）。  
7. **组织树**：层数不固定；`org_type` 仅标签；班组挂任意 `org_id`。  
8. **参评角色**：原需求侧重班组长、组长、安全员、兼职安全员；现场填姓名方案下角色可弱化/选填（待客户确认是否仍限制岗位）。  
9. **旧 bk**：只抄壳，禁止写 `qa` 库。  
10. **系统表**：管理员 `tm_admin`，角色 `tm_role`，菜单 `tm_power`，角色权限 `tm_role_power`，措施 `tm_empower_measure`，导入 `tm_import_job`，日志 `tm_op_log`。

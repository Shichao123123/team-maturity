## 2. 已完成（PC 管理端为主）

### 2.1 组织与人员

- 组织架构树：增删改、导入、任务记录  
- 班组管理：挂组织、状态、导入  
- 成员管理：事后维护；手机号可选；答题记录 / 查看结果（全屏答卷明细，按批次快照展示全部题目）  
- 列表筛选：下拉即刷、关键字防抖，去掉「查询」按钮  

### 2.2 指标 / 题库 / 等级赋能

- **指标版本**：新建草稿、编辑、发布前校验、发布、停用、深拷贝（含指标/题目/选项/措施）  
- **指标与题库**：草稿可维护指标树与题目/选项；已发布只读（需先复制）  
- 发布校验：一级权重合计≈100、每三级至少 1 题、每题至少 2 选项  
- 等级阈值、赋能措施维护（含按指标×等级）  
- PC **模拟做题**：Session 抽题 → 作答 → 算分判级看建议（不写正式批次）  

### 2.3 测评批次

- 创建 / 编辑 / 绑定班组 / 开测（写快照）/ 结束 / 算分 / 进度 / 软删  
- 创建后自动打开详情（绑班组、开测）  
- 重叠时间窗内班组占用校验（**已结束批次不再占用**）  
- 全选可选班组；详情大弹窗  
- **结束批次后自动算分**（仍可手动重算）  
- **批次二维码**：详情页展示路径码（默认 `pages/exam/index?batch_id=`），可复制  

### 2.4 结果与统计分析

- 结果查询：班组汇总、薄弱指标与措施、个人答卷、导出 Excel  
- 成熟度看板 / 成长趋势 / 班组排行榜（含导出）  
- 工作台：KPI + 分布图；支持按批次、组织筛选  

### 2.5 系统管理

- 管理员、角色菜单权限、导入任务、操作日志、登录退出  

### 2.6 小程序 API（部分）

- 微信登录 / JWT（`TmMinilogin`、`MiniJwtService`）  
- 批次班组列表、`enterBatch` 自助登记（角色固定 `member`；本批次已有答卷禁止换班组）  
- `profile`  

### 2.7 工程与质量

- Bugbot 相关修复：`dev_login` 默认关、算分包事务、登记提权与换班组问题等  
- 主要 Service / Controller / Model 已补中文 PHPDoc  
- 联调脚本：`scripts/test-batch-lifecycle.php`、`scripts/test-mini-self-register.php`

## 4. 关键业务约定（已落地）

1. **不必预导人员**：扫码选班组 + 填姓名入库（仅进行中批次可进）。  
2. **开测写快照**：答题与算分只认快照。  
3. **一班组同一时间段**仅能绑一个未结束批次。  
4. **班组均分**只计已提交；无人提交无有效班组结果。  
5. **自助登记角色固定 member**，不接受客户端传 `role_code`。  
6. **草稿改题库，已发布只读**；改标准请复制版本再发布。  

---

## 5. 建议接手顺序

1. **小程序答题**：`startPaper`（读快照）→ 保存答案 → `submit`（个人算分落库）→ 查本人/班组结果。  
2. 配微信后接正式登录与小程序码；否则联调保持 `dev_login=true`。  
3. 用已发布指标版本走一遍：建批次 → 绑组 → 开测 →（待小程序答完）→ 结束算分 → 结果/看板。  
4. 同步更新 `docs/02-admin-api.md` 与演示勾选清单。

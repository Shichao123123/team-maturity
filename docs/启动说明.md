# 本地启动说明

本文教你如何在本机启动 **PC 管理端** 和 **微信小程序答题端**。

---

## 一、环境要求（已装可跳过）

| 项 | 本机约定 |
|----|----------|
| PHP | `D:\phpstudy_pro\Extensions\php\php7.3.4nts\php.exe` |
| MySQL | `127.0.0.1` / 库 `team_maturity` / `root` / `123456` |
| 微信开发者工具 | [官方下载](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) |

数据库需已导入 `sql/` 下脚本（首次部署时执行）。

---

## 二、启动 PC 管理端

在项目根目录打开 PowerShell：

```powershell
cd d:\phpstudy_pro\WWW\team-maturity
powershell -ExecutionPolicy Bypass -File scripts\start-dev.ps1
```

若该脚本不可用，可直接：

```powershell
cd d:\phpstudy_pro\WWW\team-maturity
powershell -ExecutionPolicy Bypass -File scripts\start-mini-api.ps1
```

（`start-mini-api.ps1` 会监听 `0.0.0.0:8088`，PC 与小程序都能用。）

浏览器打开：

| 项 | 值 |
|----|-----|
| 地址 | http://127.0.0.1:8088/ |
| 账号 | `admin` |
| 密码 | `123456` |

### PC 端演示前准备（小程序要答题时）

1. 登录后台 → **测评批次**
2. 创建批次（绑定已发布指标版本）→ **绑定班组** → **开测**（写入试卷快照）
3. 批次详情页可看到**微信正式小程序码**（已配 `wx_appid`/`wx_secret`）；未发版时 `config.local.php` 设 `wxacode_env => 'develop'`
4. 备用路径：`pages/exam/index?batch_id=批次ID`（开发者工具可直接编译进场）

## 三、启动微信小程序

### 1. 确认后端已开

浏览器访问 http://127.0.0.1:8088/ 能打开后台即可。

本地联调配置在（**勿提交 Git**）：

`backend/application/config.local.php`

需包含类似内容：

```php
return [
    'wx_appid'    => 'wxc23577d86aaf957c',
    'wx_secret'   => '你的AppSecret',
    'dev_login'   => true,        // 本地联调必须 true；上线改 false
    'wxacode_env' => 'develop',   // 未发版 develop；体验版 trial；正式版 release
];
```

没有该文件时，可复制：

```powershell
copy backend\application\config.local.php.example backend\application\config.local.php
```

再自行填写 Secret，并设 `dev_login => true`。

### 2. 用微信开发者工具打开

1. 打开微信开发者工具  
2. **导入项目**，目录选：

   `d:\phpstudy_pro\WWW\team-maturity\miniprogram`

3. AppID 填：`wxc23577d86aaf957c`  
4. 右上角 **详情 → 本地设置**，勾选：

   - **不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书**

5. 确认 `miniprogram/config.js` 里：

```js
baseUrl: 'http://127.0.0.1:8088'
```

### 3. 编译进场页（模拟扫码）

开发者工具顶部 → **编译模式** → **添加编译模式**：

| 项 | 填什么 |
|----|--------|
| 模式名称 | 进场答题 |
| 启动页面 | `pages/exam/index` |
| 启动参数 | `batch_id=42`（改成你后台「进行中」批次的真实 ID） |

点编译后流程：

**选班组 → 填姓名 → 开始答题 → 逐题选择 → 全部答完提交 → 看个人结果**

首页「我的测评」可查看已参与批次。

## 四、真机预览（可选）

1. 电脑与手机同一 WiFi  
2. 后端必须用监听全网卡的方式启动：

```powershell
powershell -ExecutionPolicy Bypass -File scripts\start-mini-api.ps1
```

3. 查电脑局域网 IP（示例 `192.168.1.3`），改 `miniprogram/config.js`：

```js
baseUrl: 'http://192.168.1.3:8088'
```

4. 开发者工具点 **预览**，手机扫码进入

模拟器调试改回 `http://127.0.0.1:8088` 即可。

## 五、常见问题

| 现象 | 处理 |
|------|------|
| 登录失败 / invalid code | 确认 `config.local.php` 里 `dev_login => true`，并重启 PHP 服务 |
| 请求失败 / 连不上后端 | 先开 `scripts\start-mini-api.ps1`；开发者工具勾选「不校验合法域名」 |
| 进入批次提示尚未开测 | PC 后台对该批次点 **开测** |
| 没有可选班组 | PC 后台给该批次 **绑定班组** |
| `batch_id` 无效 | 用进行中（status=1）且已开测的批次 ID |
| 真机访问不到 | `baseUrl` 用局域网 IP；确认防火墙放行 8088；后端用 `0.0.0.0` 监听 |

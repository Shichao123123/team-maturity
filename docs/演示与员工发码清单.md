## B. 员工发码上线（4～8）— 与 A 并行准备

> 手机微信扫 PC 导出的正式码，必须走公网 HTTPS + 合法域名。本地 `127.0.0.1` / 局域网 HTTP **不能**给普通员工用。

### 4. 准备公网 HTTPS

需要运维/服务器提供：

| 项 | 要求 |
|----|------|
| 域名 | 如 `https://tm.example.com`（须备案按当地要求） |
| 证书 | 有效 HTTPS（微信不接受自签/纯 HTTP） |
| 部署 | 将本项目 `backend/public` 指到该站点；PHP ≥ 7.3；MySQL 导入 `sql/` |
| 防火墙 | 仅开放 443（及必要管理端口） |

### 5. 微信公众平台配置合法域名

登录 [微信公众平台](https://mp.weixin.qq.com/) → 你的小程序  
**开发 → 开发管理 → 开发设置 → 服务器域名**

| 类型 | 填写 |
|------|------|
| request 合法域名 | `https://tm.example.com`（只填域名，不要路径、不要端口） |
| 其它 | 暂可不填（无 uploadFile/downloadFile/socket 可先空） |

保存后一般几分钟生效。

### 6. 改小程序接口地址

发布前改 `miniprogram/config.js`：

```js
baseUrl: 'https://tm.example.com'
```

（换成你的真实 HTTPS 域名，末尾不要 `/`。）

### 7. 发体验版 / 正式版 + 环境参数

| 环境 | `config.local.php` / 服务器配置 | 微信侧 |
|------|----------------------------------|--------|
| 体验给内部试 | `wxacode_env => 'trial'`，`dev_login => false` | 上传代码 → 提交体验版 → 加体验成员 |
| 正式给员工 | `wxacode_env => 'release'`，`dev_login => false` | 提交审核 → 发布 |

服务器上务必：

```php
'dev_login'   => false,   // 走真实 wx.login
'wxacode_env' => 'release', // 或 trial
'wx_appid'    => 'wxc23577d86aaf957c',
'wx_secret'   => '生产 Secret（勿提交 Git）',
```

可用环境变量：`TM_WX_APPID` / `TM_WX_SECRET` / `TM_WX_DEV_LOGIN`。

PC 重新导出小程序码（点「刷新小程序码」再导出），确保码环境与已发布版本一致。

失败对照：

| 现象 | 处理 |
|------|------|
| fail url in domain | 合法域名未配或仍是 HTTP/IP |
| 开发版无法打开 | 码是 develop，需发体验/正式并改 `wxacode_env` |
